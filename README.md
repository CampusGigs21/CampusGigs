# CampusGigs

**CampusGigs** is a modern Progressive Web App (PWA) that connects university students with flexible part-time shifts near campus.

Students can browse, apply, and track gigs, while agencies and clients can post shifts and manage applicants — all from a clean, mobile-friendly interface.

---

## Features

### For Students
- Browse available gigs by category (Hospitality, Events, Logistics, Tutoring)
- Search and filter shifts
- One-click apply to gigs
- Track booked and completed shifts
- View earnings summary and payout history

### For Agencies / Clients
- Post new shift requests quickly
- Review student applicants
- Approve or reject applications
- Manage active shift dispatches

### PWA Features
- Installable on mobile and desktop
- Offline support via Service Worker
- Dark mode
- Smooth role switching (Student ↔ Agency)

---

## Tech Stack

- Vanilla HTML, CSS & JavaScript
- Tailwind CSS (CDN)
- Lucide Icons
- LocalStorage for data persistence
- Progressive Web App (Manifest + Service Worker)

---

## How to Run Locally

1. Download or clone this repository
2. Open `index.html` in your browser
3. That’s it — no installation or build step required
